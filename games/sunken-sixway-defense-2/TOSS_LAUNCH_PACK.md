# 선큰 식스웨이 디펜스 2 토스 출시 문안

Last updated: 2026-03-23

## 앱 이름

- 기본 표시명: `선큰 식스웨이 디펜스 2`
- 콘솔 `appName`: `sunkendefense2`
- 실제 제출 전에는 토스 개발자센터의 `appName` / `displayName`과 완전히 일치하도록 맞춥니다.

## 한 줄 소개

- 육방향 길목에 선큰을 배치하고 카드 보상으로 전열을 성장시키는 세로형 타워 디펜스 게임

## 짧은 소개

- 여섯 갈래 길을 따라 내려오는 적을 막으며 기본, 속사, 탱커, 광역, 해머 선큰을 조합해 버티는 캐주얼 전략 디펜스입니다.

## 상세 소개

- `선큰 식스웨이 디펜스 2`는 세로 화면에 최적화된 실시간 타워 디펜스 게임입니다.
- 매 스테이지마다 짧은 배치 턴이 주어지고, 전투는 자동으로 진행됩니다.
- 플레이어는 골드로 선큰을 배치하거나 강화하고, 스테이지 클리어 때마다 카드 보상을 골라 사거리, 공격력, 시작 자원, 배치 시간 같은 전장 능력을 성장시킵니다.
- 적은 정면 한 줄이 아니라 육방향 갈래를 따라 밀려오기 때문에 한쪽만 막는 운영으로는 오래 버티기 어렵고, 어느 라인에 어떤 선큰을 세울지 판단하는 전략이 핵심입니다.
- 토스 런타임 기준으로 세로 고정, Safe Area 대응, 뒤로가기 종료 모달, 홈 이동 일시정지, 보상형 광고 1회 부활 흐름까지 반영했습니다.

## 핵심 포인트

- 장르: 세로형 타워 디펜스 / 캐주얼 전략 / 웨이브 생존
- 조작: 화면 터치로 타워 배치, 강화, 판매
- 전투 흐름: 배치 턴 -> 자동 전투 -> 카드 선택 -> 다음 스테이지
- 핵심 재미: 육방향 길목 관리, 타워 조합, 카드 성장, 짧은 반복 플레이
- 세션 길이: 짧게 재도전하기 좋고, 길게는 연속 스테이지를 이어가는 구조

## 심사/운영 메모

- 세로 화면 전용으로 설계되었습니다.
- 토스 Safe Area 값을 반영합니다.
- 토스 뒤로가기 이벤트는 즉시 종료가 아니라 종료 확인 모달로 연결됩니다.
- 앱이 백그라운드로 가면 게임 진행은 자동으로 멈춥니다.
- 오디오 설정은 로컬 저장소에 저장됩니다.

## 광고 및 수익화 상태

- 현재 버전은 보상형 광고 1회 부활 로직을 포함합니다.
- 실제 출시 전에는 테스트 광고 그룹 ID 대신 운영용 광고 그룹 ID를 연결해 최종 확인하는 편이 안전합니다.
- 광고가 준비되지 않은 환경에서는 일반 재시작 흐름만 사용됩니다.

- 서브 문구: `배치 턴 한 번이 전장을 바꾼다`

### C안

- 메인 타이틀: `선큰 식스웨이 디펜스 2`

## QR 테스트 체크리스트

### 기본 동작

- 첫 진입 후 메뉴 오버레이와 시작 버튼이 정상 노출되는지 확인
- 세로 고정이 유지되는지 확인
- Safe Area 상단/하단 여백이 잘리지 않는지 확인
- 타워 배치, 강화, 판매가 정상 동작하는지 확인

### 전투 흐름

- 배치 턴 종료 후 자동 전투로 자연스럽게 넘어가는지 확인
- 스테이지 클리어 후 카드 선택 오버레이가 정상 표시되는지 확인
- 카드 선택 후 다음 스테이지로 이어지는지 확인
- 게임오버 시 재시작 흐름이 정상 동작하는지 확인

### 광고/백그라운드

- 보상형 광고가 연결된 환경에서 1회 부활이 정상 동작하는지 확인
- 홈 이동 또는 앱 백그라운드 전환 시 진행이 멈추는지 확인
- 복귀 후 게임 상태가 비정상적으로 빨라지거나 꼬이지 않는지 확인

### 네비게이션/종료

- 토스 뒤로가기 시 종료 확인 모달이 뜨는지 확인
- 종료 모달에서 `계속` / `종료` 버튼이 각각 정상 동작하는지 확인
- 종료 후 다시 진입했을 때 첫 화면이 정상 표시되는지 확인

## 출시 직전 최종 체크

1. 토스 개발자센터의 실제 `appName`과 `.ait` 내부 `appName`을 일치시킵니다.
2. 토스 개발자센터 아이콘과 `brand.icon`의 HTTPS PNG URL을 일치시킵니다.
3. `npm run build:web && npm run build`로 `.ait`를 다시 생성합니다.
4. `.ait` 생성 후 `strings -n 6` 검증으로 이름과 아이콘 반영을 재확인합니다.
5. QR 테스트를 최소 1회 이상 완료한 뒤 심사 요청을 진행합니다.
