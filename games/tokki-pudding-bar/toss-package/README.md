# tokki-pudding-bar Toss Package

## commands
- `npm run build:web`
- `npm run build`

## note
- 브리지는 `games/tokki-pudding-bar/toss-bridge-source.js`를 `esbuild`로 번들합니다.
- 배경음악은 `games/tokki-pudding-bar/assets/audio/`에서 웹 번들로 복사됩니다.
- 아이콘은 `TOSS_BRAND_ICON_URL` 또는 기본 HTTPS PNG URL을 사용합니다.
- 제출용 값과 산출물 목록은 `games/tokki-pudding-bar/TOSS_LAUNCH_PACK.md`를 따릅니다.
