Editorial Notes

메인 페이지는 프로젝트 개수를 과시하는 곳이 아니라, 지금도 설명과 운영을 이어가는 페이지를 소개하는 허브로 유지합니다.

왜 홈에서 카드 수를 줄였나

과거에는 실험 빌드와 짧은 아케이드까지 한 화면에 모두 나열했습니다. 지금은 사용자가 실제로 읽고 플레이할 수 있는 밀도를 우선하기 위해, 상위 큐레이션 작품만 남기고 홈 카드를 정리했습니다.

  • 첫 진입에서 무엇을 플레이해야 하는지 바로 보이도록 편집
  • 비슷한 장르라도 서로 다른 플레이 문법을 가진 프로젝트만 선택
  • 설명과 운영 페이지가 없는 실험성 빌드는 메인 노출에서 제외

프로젝트 페이지에서 보는 것

대표 프로젝트는 단순 실행 화면에 머물지 않도록 조작, 목표, 플레이 포인트, 업데이트 의도를 함께 적습니다. 게임을 켜기 전과 후의 이해 차이를 줄이는 것이 목적입니다.

  • 장르와 핵심 조작을 홈 카드에서 먼저 표시
  • 각 프로젝트는 직접 제작 코드와 자산 출처 문맥을 유지
  • 문의, 정책, 저작권 신고 경로를 루트에서 항상 노출

Reader FAQ

사용자가 가장 자주 묻는 운영 질문을 루트에서 바로 답합니다. 홈에서 실체와 운영 범위를 한 번에 확인할 수 있게 두었습니다.

이 사이트는 직접 만든 프로젝트만 다루나요?

네. 메인에 노출하는 게임과 데이터 앱은 직접 제작하거나 직접 운영하는 프로젝트만 유지합니다. 외부 리디렉션 모음이나 임베드형 링크 농장은 올리지 않습니다.

왜 일부 오래된 게임이 홈에서 보이지 않나요?

홈은 현재도 설명과 운영이 이어지는 대표 페이지 위주로 정리했습니다. 완성도나 문서 밀도가 부족한 실험성 빌드는 공개 URL은 유지하되 메인 노출에서는 제외합니다.

문의나 권리 침해 신고는 어디서 하나요?

루트의 Contact, Privacy, Terms, DMCA 문서에서 즉시 확인할 수 있습니다. 이메일과 GitHub 이슈 채널을 모두 열어 두고, 권리 침해 신고는 우선 검토 대상으로 처리합니다.
