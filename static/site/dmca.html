  • 침해를 주장하는 대상 콘텐츠의 정확한 URL

  • 선의 신고 진술과 전자 서명 또는 이에 준하는 확인

접수 방법

이메일 wndzlf@gmail.com 또는 GitHub Issues 로 접수할 수 있습니다. 권리 침해 신고는 일반 개선 요청보다 우선 처리합니다.

처리 원칙

  • 신고 내용이 충분한 경우 임시 비노출 또는 검토 보류 조치를 할 수 있습니다.
  • 반론 통지 또는 추가 자료 요청이 필요한 경우 신고자와 별도로 연락할 수 있습니다.
  • 허위 또는 반복적인 남용 신고는 제한될 수 있습니다.

자산 사용 원칙

프로젝트는 직접 제작 자산을 기본으로 하며, 외부 자산을 사용할 때는 라이선스 조건을 확인하고 필요한 경우 프로젝트 문서에 출처를 표시합니다.
