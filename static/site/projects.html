전체 프로젝트 보기

메인 홈은 대표작 위주로 큐레이션하지만, 현재 공개 중인 프로젝트 전체 목록은 이 페이지에서 바로 접근할 수 있습니다. 웹게임, 데모, 서울·경기 데이터 유틸리티까지 공개 URL 기준으로 한 번에 모았습니다.

2026년 5월 1일 기준 공개 프로젝트는 총 67개입니다. 내부 서브페이지나 리다이렉트용 엔드포인트는 제외하고, 실제로 플레이하거나 사용할 수 있는 루트 URL만 남겼습니다.

홈으로 돌아가기 대표 프로젝트 보기
  • 67 현재 공개 중인 전체 프로젝트 수
  • 64 게임 · 데모 · 쇼케이스 프로젝트
  • 3 서울·경기 데이터 유틸리티 앱

이 페이지 사용법

홈에서 안 보이는 프로젝트도 여기서는 직접 열 수 있습니다. 장르별로 크게 묶어 두었고, 각 카드에는 제목과 공개 경로를 함께 표기했습니다.

  • 메인 홈에 없는 오래된 실험작도 공개 중이면 여기서 접근 가능
  • 게임과 데이터 앱을 같은 페이지에서 찾을 수 있도록 통합 정리
  • 공개 루트 URL만 남겨서 실제 진입 가능한 링크만 제공
  • 대표작 설명은 홈에서, 전체 접근은 이 아카이브에서 담당
